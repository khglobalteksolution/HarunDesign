# HarunDesign Portfolio Web App

A simple, functional, and mobile-friendly multi-page portfolio website for **Khgfunder1**, a professional crowdfunding promoter.

## Pages
- **Home** (`index.html`) – introduction, quick stats, and service highlights.
- **About Us** (`about.html`) – background, mission, and process.
- **Reviews** (`reviews.html`) – client testimonials with platform filters.
- **Contact** (`contact.html`) – direct links plus a simple contact form interaction.

## Features
- Responsive navigation and layout for mobile and desktop.
- Suitable professional color palette and readable UI.
- Interactive review filtering by platform.
- Contact details:
  - Email: [khgfunder@gmail.com](mailto:khgfunder@gmail.com)
  - X (Twitter): [@khgfunder](https://x.com/khgfunder)

## Run locally
```bash
python -m http.server 4173
```
Then open `http://127.0.0.1:4173`.
